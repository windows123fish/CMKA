CMKA — это приложение для детектирования объектов в реальном времени на основе **YOLO26n** и **Ultralytics** с элегантным графическим интерфейсом, построенным с использованием PyQt5.

## Основные функции

- ✅ **Обнаружение в реальном времени с камеры** - Поддержка переключения между несколькими камерами
- ✅ **80 категорий объектов** - Включает людей, транспортные средства, животных, повседневные предметы, еду и т.д.
- ✅ **Отображение меток на китайском** - Ясное отображение названий категорий на китайском с использованием PIL
- ✅ **Фильтрация категорий** - Настраиваемое отключение определенных категорий
- ✅ **Отслеживание объектов** - Автоматическое отслеживание целей с уникальным ID
- ✅ **Отрисовка траектории** - Запись и отображение пути движения объекта (кроме людей)
- ✅ **Прогнозирование положения** - Прогнозирование положения на следующем кадре (кроме людей)
- ✅ **Настройки траектории** - Настраиваемое отображение и цвета траектории
- ✅ **Элегантный интерфейс** - Кастомная строка заголовка и дизайн окон с закругленными углами
- ✅ **Управление окном** - Поддержка сворачивания, разворачивания и перетаскивания

```bash

python main.py
```

## Использование

1. Запустите приложение
2. Введите код проверки `Windows123fish`
3. Выберите доступную камеру в диалоге
4. Нажмите "Начать обнаружение" для запуска детектирования в реальном времени
5. Нажмите "Отключить категории" для исключения определенных объектов
6. Нажмите "Настройки траектории" для конфигурации отображения и цветов

## Настройки траектории

- **Показать траекторию** - Отображает путь движения объекта при включении
- **Показать прогноз** - Отображает прогнозируемое положение (желтая точка) при включении
- **Цвет траектории** - Красный, синий, зеленый, желтый, фиолетовый, белый
- **Цвет прогноза** - Желтый, красный, синий, зеленый, фиолетовый, белый

> **Примечание**: Траектория и прогноз не отображаются для людей (person)
